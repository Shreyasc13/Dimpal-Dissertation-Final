Assumptions and limitations

  • Simulated data: the Kaggle file is simulated. Each failure flag follows a fixed rule (actuator: load > 70 or landing cycles > 401), which is why the forecasts are so accurate.
  • Unit cost ₹43,20,000 per actuator; holding cost 25% per year, so one extra unit for one batch costs ₹1,08,000.
  • Fleet utilisation 2,000 landings per year, so one batch of 200 landings ≈ 0.1 year (about 36 days).
  • AOG cost from public industry ranges, converted at ₹96/US$, with an 18-hour grounding per shortage. Each unit short counts as one grounding.
  • Order cost (admin, freight, inspection) is a guess; change it above to see the effect on order size.
  • Parts ordered for a batch are assumed to arrive before that batch starts.
  • The forecast uses each landing's conditions (load, cycles, …). In real use these would come from flight plans and known aircraft cycle counts.
  • Only 50 batches exist, which is too few to test rare stockouts properly. No method ran short in this test.
